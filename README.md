# Basit Elektronik Harp Simülasyonu

Bilgisayar Mühendisliği Bölümü proje çalışması. Greenfoot ortamında temel radar taraması, hedef tespiti ve elektronik karıştırma (jamming) mekaniklerinin simüle edilmesi amaçlanmaktadır.

**Proje Danışmanı:** Dr. Öğr. Üy. Atilla Özgür

## Planlanan Özellikler

1. **Radar Taraması ve Tespit:** 360 derece dönen radar anteni ve menzile giren hedeflerin ekranda gösterilmesi.
2. **Gürültü Karıştırması (Noise Jamming):** Karıştırıcı uçağın radara gürültü sinyali göndererek o açıda körleme yapması.
3. **Aldatma ve Chaff:** Radar ekranında sahte hedef veya yanıltıcı bulut oluşturma.

## Klasör Yapısı

- `src/` : Greenfoot senaryosu ve Java sınıfları
- `docs/` : Radar ön araştırması ve proje dokümanları
